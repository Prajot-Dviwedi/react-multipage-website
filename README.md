# React Multi-Page Website

A simple multi-page website built using React.js and React Router DOM.

### Pages
- Home
- Login
- Contact
- Services

### Technologies Used
- React.js
- JavaScript
- CSS
- React Router DOM

### Getting Started

```bash
npm install
npm run dev
```
